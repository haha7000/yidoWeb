1. 시스템 개요

  • 영수증과 여권 이미지의 자동 인식
  • 영수증과 엑셀 데이터의 자동 매칭
  • 고객별 구매 데이터의 종합 분석

2. 회원가입 및 로그인

1
회원가입 하기

처음 사용자는 "회원가입" 버튼을 클릭하세요.

  • 아이디: 영문, 숫자 조합 (중복 확인 필수)
  • 비밀번호: 안전한 비밀번호 설정
  • 비밀번호 확인: 일치하는지 확인, 영문/숫자/특수문자 조합
  • 이메일 주소: 비상연락용 이메일
주의: 비밀번호는 안전한 곳에 별도 보관하세요. 분실 시 복구가 어려울 수 있습니다.
2
이메일 인증 및 계정 활성화

가입 후 이메일 인증을 통해 계정을 활성화하세요.

  • 인증 메일 확인 1-2분 소요
  • 인증 완료 후 비밀번호로 바로 로그인 가능
  • 인증 완료 시 확인 메시지 표시됩니다
3
로그인 및 비밀번호 찾기

비밀번호를 잊은 경우 이메일을 통해 로그인을 복구하세요.

  • 가입 시 비밀번호로 로그인
  • 비밀번호 찾기 기능 (이메일로 재설정 링크)
  • 로그인 시 브라우저에 아이디 저장 권장

3. 데이터 업로드

1
엑셀 파일 업로드 (필수)

각 면세점에서 제공한 매출 데이터 엑셀 파일을 업로드하세요.

롯데 면세점 엑셀 형식
  • 영수증번호, 고객명, 생년월일
  • 카테고리명, 브랜드명, 상품명
  • 판매금액, 할인액, 순매출액
신라 면세점 엑셀 형식
  • 생년월일, 성명, 성씨명
  • 영수증번호, 카테고리 정보
  • 판매금액, 할인액 정보
팁: 업로드 전 엑셀 파일의 열 제목이 정확한지 미리 확인하면 처리속도가 빨라집니다.
2
이미지 파일 업로드

영수증 및 여권 이미지를 ZIP 파일로 압축해 업로드하세요.

지원하는 이미지 형식
  • 파일 형식: JPG, PNG, JPEG
  • 권장 해상도: 최소 1000x1000 픽셀
  • 파일 크기: 개별 10MB 이하
품질 좋은 사진
  • 영수증: 글자가 선명하게 보이도록 촬영
  • 여권: 개인 정보가 선명하게 보이도록 촬영
  • 조명: 그림자나 반사가 없도록 주의
  • 각도: 정면에서 똑바로 촬영
3
업로드 진행 상황 확인

파일 업로드 후 진행 상황을 실시간으로 확인할 수 있습니다.

  • 진행률 표시: 업로드 진행율 확인
  • 처리 상태: OCR 인식 진행 상황
  • 오류 메시지: 문제 발생 시 자세한 메시지 표시
주의사항: 업로드 중에는 페이지를 새로고침하지 마세요. 진행 상황이 초기화될 수 있습니다.

4. 데이터 처리 과정

1
OCR 자동 인식

업로드된 이미지에서 텍스트를 자동으로 인식합니다.

영수증 인식
  • 영수증 번호 추출
  • 구매 금액 인식
  • 카테고리 및 상품명 인식
여권 인식
  • 여권 번호 추출
  • 성명 (한글명/영문명)
  • 생년월일
2
AI 기반 데이터 분류

GPT-4를 사용해 인식된 텍스트를 의미있는 데이터로 분류합니다.

  • 영수증: 영수증 번호 등 핵심 정보 추출
  • 여권: 개인 신원 정보 추출
  • 분류: 영수증/여권/기타 등의 이미지 분류
3
데이터 매칭 과정

인식된 데이터를 엑셀의 매출 데이터와 자동으로 매칭합니다.

롯데 매칭 방식
  • 1차: 영수증 번호로 매칭
  • 2차: 여권 성명으로 고객 확인
  • 3차: 매칭 결과 검증
신라 매칭 방식
  • 1차: 영수증 번호로 매칭
  • 2차: 여권 번호로 연결
  • 3차: 성명 확인 검증

5. 매칭 관리

1
매칭되지 않은 영수증 처리

자동 매칭이 실패한 영수증을 수동으로 처리하세요.

  • 영수증 이미지 확인: 실제 번호와 OCR 인식 결과 비교
  • 번호 수정: 잘못된 영수증 번호 수정
  • 수동 매칭: 올바른 고객과 엑셀 데이터를 매칭 처리
매칭 성공 시 처리: "매칭 성공" 메시지와 함께 다음 미매칭 영수증으로 자동 이동합니다.
매칭 실패 시 처리: "매칭 실패" 메시지와 함께 현재 페이지에 머물러 재시도할 수 있습니다.
2
매칭되지 않은 여권 처리

자동 매칭이 실패한 여권을 수동으로 처리하세요.

  • 성명 수정: 엑셀 데이터와 일치하는 실제 성명으로 수정
  • 성씨명 수정: 신라 면세점의 경우 성씨명을 수정
  • 생년월일: 올바른 날짜 형식으로 생년월일 수정
팁: 성명을 엑셀 데이터와 정확히 일치시켜야만 매칭됩니다. 띄어쓰기나 실제 성명도 정확히 수정하세요.
3
이미지별 상세 확인

각각 인식된 이미지의 세부 정보를 확인할 수 있습니다.

  • 영수증 상세보기: 원본 이미지와 인식된 텍스트 확인
  • 여권 상세보기: 원본 이미지와 인식된 텍스트 확인
  • 인식 안된 이미지: 분류되지 않은 이미지들 별도 관리
  • 오류: 인식과정의 이미지 오류
4
대량 업데이트 및 검증

여러개의 데이터를 한번에 효율적으로 처리하세요.

  • 이미지 미리보기: 여러 이미지를 한번에 빠르게 미리보기
  • 파일 검색: 특정 키워드 이미지를 파일 검색
  • 일괄 수정태그: 엑셀 제목을 여러 성명으로 파일 수정태그

6. 결과 확인 및 관리

1
매칭 결과 대시보드

전체 처리 현황을 한눈에 확인할 수 있습니다.

  • 매칭된 영수증: 완료된 건수, 매칭 성공률
  • 매칭된 여권: 성공적으로 매칭 데이터 현황
  • 매칭되지 않은 영수증: 처리가 필요한 오류 항목
  • 매칭/매칭되지 않은 여권: 현재 처리 현황
2
고객별 상세 정보

각 고객의 구매 내역을 상세히 확인할 수 있습니다.

  • 고객 정보: 성명, 성씨명, 생년월일
  • 구매 내역: 상품별 구매 금액
  • 상품명 정보: 판매금액, 할인액, 순매출액
  • 매칭 상태: 구매 및 여권 매칭
3
검색 및 필터링

특정 데이터를 빠르게 찾아 자세한 정보를 필터링할 수 있습니다.

  • 고객명 검색: 특정 고객 데이터를 필터링
  • 영수증 번호 검색: 영수증 번호로 바로 찾기
  • 기간별 검색: 수정하고자 하는 기간별 필터링

7. 수수료 계산

1
자동 수수료 계산

매칭이 완료된 데이터를 바탕으로 정확한 수수료를 자동 계산합니다.

수수료 계산 우선순위
  1. 개별상품 수수료 (최우선)
  2. 브랜드별 수수료
  3. 상품군별 수수료
  4. 기본 수수료 (기본값)
2
할인율 무료 수수료 계산

특정의 비율 이상의 할인 상품에는 수수료를 자동 면제합니다.

  • 무료 기준율: 특정 할인율 이상 0%
  • 엑셀 할인율: 파일 할인율 확인 후 자동 0%
  • 정책 적용: 면세점별 정책 할인 면제 정책
3
결과 확인 및 조정

계산된 결과를 확인하고 필요시 조정할 수 있습니다.

  • 상세 내역: 항목별 자세한 수수료 계산 내역 확인
  • 총합: 고객별, 전체 총합 금액
  • 수동 조정: 특정한 케이스 수동 조정 기능

8. 수령증 생성

1
고객별 수령증 파일 생성

매칭이 완료된 데이터로 자동 수령증을 생성합니다.

  • 고객 정보: 각 고객의 상세 엑셀 파일 생성
  • 구매내역: 상품별 구매 상세 내역
  • 상세 내역: 구매 항목별 상세 금액
  • 수수료 내역: 상품 수수료 내역
2
파일 다운로드

생성된 수령증을 원하는 형태로 다운로드할 수 있습니다.

  • ZIP 파일: 고객별 수령증을 모두 포함한 ZIP 파일로
  • 파일명 규칙: "수령증_고객명.xlsx" 형태
  • 개별 다운로드: 다운로드 후 특정 파일 개별 다운로드
3
세션 완료 및 정리

모든 처리가 완료된 세션을 완료하고 데이터를 정리합니다.

  • 세션 완료: 처리 작업을 정리하고 다음 작업
  • 데이터 정리: 임시 데이터를 브라우저에서 정리
  • 이력 저장 여부: 다시 조회할 이력 저장 정리 부여
  • 새로운 작업 시작: 정리 후 새로운 작업 세션 확인 가능

10. 문제 해결

자주 발생하는 문제들

해결 방법:

  • 이미지 품질을 높게 다시 촬영
  • 조명을 밝게 하고 그림자 제거
  • 정면에서 똑바로 촬영
  • 매칭되지 않은 항목을 수동으로 수정

확인 사항:

  • 엑셀 파일이 .xlsx 또는 .xls 형식인지 확인
  • 파일의 열 제목이 정확한 데이터가 포함되었는지 확인
  • 빈 행이나 잘못된 데이터가 있는지 확인
  • 파일이 손상되지 않았고 열기에서 키워드가 올바른지 확인

확인 사항:

  • 영수증 번호가 엑셀 데이터와 정확히 일치하는지 확인
  • 고객 성명 표기가 엑셀과 일치하는지 확인
  • 면세점 구분(롯데/신라)이 정확한지 확인
  • 데이터 형식이 일치하는지 확인

확인 사항:

  • 매출액과 수수료 등급 확인
  • 특정 할인상품 및 할인율 수수료 면제 확인
  • 계산 기준 파일이 정확한지 확인
  • 수수료 상품군 분류가 올바른지 확인

해결 방법:

  • 브라우저 캐시를 삭제하고 페이지를 새로고침 해보세요
  • "이미지 미리보기" 버튼을 클릭해서 다음 페이지
  • 페이지 새로 파일 업로드하신 후 다시 시도해 보세요
  • 문제가 지속되면 관리자에게 문의

해결 방법:

  • 매칭이 완료된 데이터가 있는지 확인
  • 파일명에 특수문자가 있는지 확인
  • 다운로드 권한이 허용되어 있는지 확인
  • 네트워크 연결 상태 확인
추가 지원

위 해결 방법으로 문제가 해결되지 않으면 다음 방법을 시도해보세요:

  • 관리자에게 문의: 시스템 관리자에게 구체적 문의
  • 스크린샷 첨부: 오류 메시지를 포함한 화면을 캡처해서 제보
  • 상세 설명: 어떤 단계에서 문제가 발생했는지 상세하게 설명

11. 유용한 팁

효율성 증대 방법
이미지 촬영 팁
  • 조명: 밝은 자연광 또는 LED 조명 사용
  • 각도: 정면 각도(기울어진 각도 피하기)
  • 배경: 깔끔한 배경에서 촬영
  • 이미지: 흔들림 없는 고해상도 이미지로 촬영
데이터 관리 팁
  • 엑셀 정리: 업로드 전 열 제목과 데이터 형식을 미리 정리
  • 백업 저장: 원본 데이터를 안전한 곳에 백업 저장
  • 성명 통일: 동일 고객의 파일 내 성명 통일
  • 파일명 규칙: 정리된 파일명으로 관리
시간 효율성
  • 파일 업로드: 많은 이미지 엑셀 이미지를 한번에 처리
  • 매칭 순서: 매칭되지 않은 항목부터 우선적으로 처리
  • 정기적 점검: 처리 결과 세션 완료하고 다음 단계 진행
  • 정기적으로 로그인: 장시간 이용 시 정기적으로 로그아웃 후 재로그인
보안 및 데이터 관리
  • 계정 비밀번호 관리: 정기적으로 안전한 비밀번호로 변경
  • 세션 완료: 작업 완료 후 꼭 세션 완료
  • 데이터 백업: 수령 후 지운 후 브라우저 백업 정리
  • 로그아웃: 작업 완료 후 반드시 로그아웃
성능 최적화
  • 이미지 파일 크기: 이미지는 5MB 이하로 최적화
  • 브라우저 최적화: Chrome 또는 Edge 브라우저 권장
  • 네트워크 연결: 안정된 인터넷 연결 및 와이파이 사용
  • 캐시 정리: 주기적으로 브라우저 캐시 정리
고급 활용법
  • 일괄 매칭: 시스템이 제안하는 데이터를 자동으로 매칭
  • 반복 작업: 매일 처리하는 작업의 경우 표준화 체크
  • 이미지 분류: 영수증/여권 이미지 실제 번호 및 각각 분류 저장
  • 파일 정리: 처리 완료 이미지를 일정한 폴더 체계로 정리
  • 정기적으로 데이터 관리: 주기적으로 기한 등 관리자와 고객 조정 데이터 관리
