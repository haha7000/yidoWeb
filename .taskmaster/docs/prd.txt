# 프로젝트 개요
이 프로젝트는 한국의 주요 면세점(롯데, 신라)에서 발행하는 영수증과 여권을 OCR을 통해 자동으로 처리하고 매칭하는 시스템입니다. 주요 사용자는 면세점 업무 담당자들로, 수동으로 처리하던 영수증-여권 매칭 업무를 자동화하여 업무 효율성을 크게 향상시키는 것이 목적입니다.

# 핵심 기능
현재 시스템은 다음과 같은 주요 기능들을 제공합니다:

## 1. OCR 처리 시스템
- 영수증 이미지에서 영수증 번호, 상품 정보, 매출 데이터 추출
- 여권 이미지에서 여권번호, 성명, 생년월일 추출
- GPT를 활용한 OCR 결과 검증 및 정제
- 롯데/신라 각 면세점별 서로 다른 영수증 형식 지원

## 2. 자동 매칭 시스템
- 영수증의 고객명과 여권 정보 자동 매칭
- 여권번호 기반 정확한 고객 식별
- 매칭 결과 로그 및 이력 관리
- 매칭되지 않은 데이터 수동 수정 인터페이스

## 3. 수수료 계산 시스템
- 카테고리별/브랜드별/품목별 차등 수수료 적용
- 할인율 기반 수수료 제외 로직
- 수수료 설정 관리 (기간별, 면세점별)
- 수수료 제외 브랜드 관리

## 4. 다국어 웹 인터페이스
- 한국어/중국어 지원
- 반응형 웹 디자인
- 사용자 인증 및 권한 관리
- 실시간 처리 결과 확인

## 5. 데이터 관리 시스템
- 처리 완료 데이터 아카이브
- 세션별 데이터 관리
- 엑셀 업로드/다운로드
- 처리 이력 추적

# 사용자 경험
## 주요 사용자 페르소나
- **면세점 업무 담당자**: 매일 수백 건의 영수증-여권 매칭 업무를 처리하는 직원

# 기술 아키텍처

## 시스템 구성 요소
### 백엔드 (Python FastAPI)
- **웹 프레임워크**: FastAPI (비동기 처리 지원)
- **데이터베이스**: SQLAlchemy ORM, PostgreSQL/SQLite 지원
- **인증**: JWT 기반 사용자 인증
- **파일 처리**: 이미지 업로드 및 저장 관리
- **API 설계**: RESTful API + 실시간 WebSocket 지원

### AI/ML 처리 엔진
- **OCR 엔진**: 한국어 특화 OCR (Tesseract + 커스텀 모델)
- **GPT 통합**: OpenAI API를 통한 OCR 결과 검증 및 정제
- **자동 매칭**: 이름 유사도 알고리즘 + 여권번호 기반 정확 매칭
- **데이터 검증**: 영수증 번호, 여권번호 형식 검증

### 프론트엔드 (HTML/CSS/JavaScript)
- **템플릿 엔진**: Jinja2 기반 서버사이드 렌더링
- **UI 프레임워크**: Bootstrap + 커스텀 스타일
- **파일 업로드**: 진행률 표시가 가능한 비동기 업로드
- **국제화**: 한국어/중국어 다국어 지원

### 데이터 모델
```
Users (사용자 관리)
├── Receipts (영수증 데이터)
├── Passports (여권 데이터) 
├── ShillaReceipts (신라 영수증)
├── ReceiptMatchLog (매칭 로그)
├── ProcessingArchive (아카이브)
├── ProcessingHistory (처리 이력)
└── Fee 관련 테이블들 (수수료 설정)
```

### 외부 연동
- **OpenAI GPT API**: OCR 결과 검증 및 정제
- **롯데/신라 면세점 시스템**: 향후 API 연동 예정
- **클라우드 스토리지**: 이미지 파일 저장 (AWS S3/Google Cloud)

## 인프라 요구사항
- **서버**: Linux 기반 (Ubuntu/CentOS)
- **데이터베이스**: PostgreSQL (프로덕션), SQLite (개발)
- **웹서버**: Nginx + Gunicorn
- **모니터링**: 로그 수집 및 성능 모니터링
- **백업**: 데이터베이스 정기 백업 시스템
